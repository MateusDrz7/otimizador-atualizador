# Instalação

Este guia explica como preparar o projeto para uso correto.

---

## Requisitos

- Git instalado
- conexão com a internet
- acesso ao repositório oficial
- pacote da release apropriado para o ambiente

---

## Passo a passo

### 1. Acesse o repositório

https://github.com/MateusDrz7/otimizador-atualizador

### 2. Abra a seção de releases

https://github.com/MateusDrz7/otimizador-atualizador/releases

### 3. Faça o download

Baixe a versão mais recente disponível no GitHub.

### 4. Instale ou extraia o pacote

Dependendo do tipo de arquivo disponibilizado, você pode:

- extrair para uma pasta local
- executar o instalador
- validar a inicialização do produto

### 5. Confirme a versão atual

A versão ativa do projeto fica em:

- [version.json](../version.json)

---

## Dicas importantes

- prefira sempre a versão oficial publicada no GitHub
- verifique a compatibilidade do pacote antes de instalar
- consulte o changelog antes de atualizar
- mantenha a estrutura do ambiente organizada

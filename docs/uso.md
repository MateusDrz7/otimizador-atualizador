# Uso e atualização

Este guia mostra como manter o projeto atualizado de forma segura e organizada.

---

## Fluxo recomendado

### 1. Verificar a versão atual

Confirme a versão instalada e compare com a última release disponível.

### 2. Baixar a nova versão

Acesse a página de releases e faça o download oficial do pacote mais recente.

### 3. Atualizar o sistema

Substitua a versão antiga pela nova conforme o processo do software ou pacote disponibilizado.

### 4. Validar funcionamento

Teste a aplicação após a atualização para confirmar estabilidade e compatibilidade.

---

## Boas práticas

- manter o changelog sempre consultado
- usar somente versões oficiais do GitHub
- evitar versões de terceiros ou não documentadas
- manter o ambiente organizado para facilitar troubleshooting
